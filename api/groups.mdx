The Groups API manages the topic-based support groups that live sessions are anchored to. Each group carries a `topic`, an optional `description`, and a `sessionType` that governs which participants can join — making groups the fundamental organizational unit in Sahara before any live room is created.

---

## POST /api/groups

<span style={{display:"inline-block",background:"#16a34a",color:"#fff",borderRadius:"4px",padding:"2px 8px",fontWeight:700,fontSize:"0.8rem",marginBottom:"1rem"}}>POST</span> `/api/groups`

Creates a new support group. The authenticated user does not become a participant of the group at creation time — participants are added when a session is started.

**Auth:** requires an active user session.

### Request body

<ParamField body="topic" type="string" required>
  The subject or theme of the group (e.g. `"Grief & Loss"`, `"Work Stress"`). Used as the display name throughout the UI.
</ParamField>

<ParamField body="sessionType" type="string" required>
  Governs the type of live session the group hosts. Must be one of:

  | Value | Description |
  |---|---|
  | `peer` | Anonymous peer-to-peer group session |
  | `peer_counselor` | Peer session with a verified counselor present |
  | `one_on_one` | Private one-on-one session between two users |
</ParamField>

<ParamField body="description" type="string">
  A short human-readable description of the group's purpose. Optional — stored as `null` when omitted.
</ParamField>

### Response `201`

Returns the newly created `Group` object.

<ResponseField name="id" type="string">
  UUID of the group, auto-generated by the database.
</ResponseField>

<ResponseField name="topic" type="string">
  The group's subject as provided in the request.
</ResponseField>

<ResponseField name="description" type="string | null">
  The optional description, or `null` if not provided.
</ResponseField>

<ResponseField name="session_type" type="'peer' | 'peer_counselor' | 'one_on_one'">
  The session type that was set at creation.
</ResponseField>

<ResponseField name="created_at" type="string">
  ISO 8601 timestamp of when the group was created.
</ResponseField>

### Errors

| Status | Condition |
|---|---|
| `400` | `topic` or `sessionType` is missing, or `sessionType` is not a valid value |
| `401` | No authenticated user session |
| `500` | Database insertion failure |

## GET /api/groups/[groupId]

<span style={{display:"inline-block",background:"#2563eb",color:"#fff",borderRadius:"4px",padding:"2px 8px",fontWeight:700,fontSize:"0.8rem",marginBottom:"1rem"}}>GET</span> `/api/groups/{groupId}`

Fetches a single group by its UUID. No authentication check is enforced at the route level — the Supabase RLS policies on the `groups` table govern row-level access.

### Path parameters

<ParamField path="groupId" type="string" required>
  UUID of the group to retrieve.
</ParamField>

### Response `200`

Returns the matching `Group` object with the same fields as the `POST` response above.

<ResponseField name="id" type="string">
  UUID of the group.
</ResponseField>

<ResponseField name="topic" type="string">
  The group's subject.
</ResponseField>

<ResponseField name="description" type="string | null">
  Optional description, or `null`.
</ResponseField>

<ResponseField name="session_type" type="'peer' | 'peer_counselor' | 'one_on_one'">
  The configured session type.
</ResponseField>

<ResponseField name="created_at" type="string">
  ISO 8601 creation timestamp.
</ResponseField>

### Errors

| Status | Condition |
|---|---|
| `404` | No group with the given `groupId` exists |
| `500` | Unexpected server error |

## Example

### Create a group

```bash
curl -X POST https://your-sahara-app.vercel.app/api/groups \
  -H "Content-Type: application/json" \
  -H "Cookie: <SESSION_COOKIE>" \
  -d '{
    "topic": "Anxiety & Overthinking",
    "description": "A safe space to share coping strategies for anxiety.",
    "sessionType": "peer"
  }'
```

```json
{
  "id": "e3b0c442-98fc-1c14-9afb-f4c8996fb924",
  "topic": "Anxiety & Overthinking",
  "description": "A safe space to share coping strategies for anxiety.",
  "session_type": "peer",
  "created_at": "2025-01-15T10:32:00.000Z"
}
```
